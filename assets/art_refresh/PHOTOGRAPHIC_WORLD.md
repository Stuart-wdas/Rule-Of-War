# Photographic ground and per-computer graphics

The training ground and Forward Base use the same scanned meadow material,
world-space soil shoulders, worn asphalt and clustered ground cover. The fixed
camera and approved explosion frames are preserved. The subsequent
[battlefield refresh](WORLD_DETAIL.md) adds measured ground relief, denser
understory, tracks and warmer afternoon daylight; consult it for current detail
budgets and validation results.

Open **Escape → Settings**. The right panel controls graphics. Changes apply
immediately and save beside the local game saves in `graphics-settings.json`.
These preferences are local to each laptop; they do not change multiplayer rules,
AI, collision, cover or navigation. Infantry footsteps remain disabled.

| Control | Low | Balanced | High |
| --- | --- | --- | --- |
| Terrain texture array size | 512 | 1024 | 2048 |
| Terrain array GPU memory, including mipmaps | 16 MiB | 64 MiB | 256 MiB |
| Small stones per low-growth cluster | 2 | 6 | 12 |
| Directional shadow map | 512 | 1024 | 2048 |
| Shadow cascades | 1 | 2 | 3 |
| Grass shadow radius | Off | 32 m | 64 m |
| Contact ambient occlusion | Off | On | On |

Shadow detail uses a lower rendering budget independently of visible model,
terrain and vegetation detail. All presets retain the 600-metre shadow distance.
Balanced uses one eighth of the previous shadow-map texel budget.

Explosion quality is independently adjustable. F6 also cycles it during play.
The approved mushroom and spiky animations retain their shapes and timing;
quality changes their playback resolution. Changing large textures or explosion
quality while paused can briefly rebuild assets. Ordinary explosions continue to
use the existing preloaded animation arrays.

On an RTX 3060 laptop, start with **Balanced** and **Native** at 1080p.
Try **NVIDIA DLSS / Quality** when increasing resolution or GPU-heavy settings.
Keep explosions at Balanced initially. Increase terrain textures or environment
detail independently if there is headroom. Native/FXAA remains available, and is
the fallback when the renderer/device does not expose DLSS support. DLSS requires
Vulkan and a compatible NVIDIA RTX driver. It upscales the 3D scene; the menu and
HUD remain at output resolution. This integration is Super Resolution, without
frame generation or ray reconstruction. A still image generated by AI can invent
detail that the renderer does not contain; these settings do not reproduce that
process frame by frame.

Ground texture: **Rocky Terrain 02**, Amal Kumar / Poly Haven, CC0 1.0 Universal:
https://polyhaven.com/a/rocky_terrain_02
Untouched original PNGs and source information are in
`assets/incoming_textures/rocky_terrain_02`. Runtime derivatives and hashes are in
`materials/pbr/catalog.json`. Reimport with
`assets/art_refresh/tools/import_meadow.py`; the script verifies each original.
The 90-metre aerial scan provides visible rocky patches at playing distance;
the fine grass scan supplies small-scale grain. Normal and AO/roughness maps use
the same physical scale. Mipmaps filter colour in linear light and renormalize
normals. Small rocks are batched with existing scenery, prepared off-thread and
streamed one chunk per frame; changing quality preserves world placement seeds.

Roads use **Aerial Asphalt 01**, Rob Tuytel / Poly Haven, CC0:
https://polyhaven.com/a/aerial_asphalt_01
This 30-metre scan retains cracks and tyre wear at the fixed camera's playing
distance. Its original PNGs are under `assets/incoming_textures/aerial_asphalt_01`.
Import it using `assets/art_refresh/tools/import_meadow.py --road`. When rebuilding
the entire library, run the original `import_pbr.py` first, then the meadow import,
then the road import. All supplied original archives remain untouched.

## Building and copying to another laptop

Windows builds enable Bevy 0.18.1's DLSS integration by default. The matching
`dlss_wgpu` 2 SDK is NVIDIA DLSS **v310.4.0**. Run `tools/Setup-DLSS.ps1` once on
a development machine with Git and Python if the optional build tools are absent.
Cargo reads their paths from `.cargo/config.toml`. A portable build without the
SDK is available using `cargo build --no-default-features`; it keeps the graphics
controls and native FXAA fallback.

Running a compiled build does not require the SDK. Ship `nvngx_dlss.dll`,
`NVIDIA-DLSS-LICENSE.txt` and `NVIDIA-DLSS-NOTICES.txt` beside the executable,
along with the normal game assets/materials. The build and native launcher copy
these runtime files automatically. Do not copy only the executable. The NVIDIA
release DLL is retained with its original signature. Runtime third-party notices
are preserved in `NVIDIA-DLSS-NOTICES.txt`.

Verification script: `tools/check_photographic_world.py`. It captures both maps,
the settings screen, armour sparks and the mushroom base ring, then runs sequential
native/DLSS battle benchmarks with external Windows CPU/GPU measurements.

The wrapper/engine compatibility patches are documented in `native/vendor/README.md`.
They fix NGX command ordering, raw descriptor lifetimes and the fixed-quality input
resolution without upgrading the rest of the engine.

## Local validation

314 unit/regression tests pass; strict Clippy passes. Native render checks cover
both maps, the settings page, switching every DLSS mode and returning to native,
texture-budget changes, armour-hit sparks and mushroom ground dust.

Sequential 30-second combined-arms tests on the local RTX 3060 Laptop GPU:

| Rendering | Median frame | 95th percentile |
| --- | --- | --- |
| Previous build, 1100 × 850 | 14.77 ms | 21.32 ms |
| New Balanced/native, 1100 × 850 | 14.79 ms | 20.14 ms |
| Final surfaces, Balanced/native, 1920 × 1080 | 14.63 ms | 20.67 ms |
| Final surfaces, Balanced/DLSS Quality, 1920 × 1080 | 14.99 ms | 19.39 ms |

These are development-build samples, not guaranteed FPS on another laptop.
DLSS adds an approximately 1 ms reconstruction pass and did not improve the
median at these tested resolutions, so native remains the default. It is an
optional tradeoff for higher GPU load. Explosion quality was held at Balanced.
The compact tests preceded the last road-map replacement; the 1080p tests use
the final surfaces. Raw CPU/GPU samples and summaries are under
`.data/render-checks/photographic-world` and `.data/battle-bench/photo-*`.
